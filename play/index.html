Every point you place is a training example with two features — its x and y coordinate — and a binary label. The network runs a forward pass, measures binary cross-entropy against the label, then propagates the gradient back through each layer and nudges every weight against it. The background is the model's current output over a 64×64 grid of the input space, sampled fresh on each render: teal where it predicts class A, violet where it predicts class B, and washed out wherever it isn't confident.

Try XOR with zero hidden layers. It will never separate — a linear model can't. Add one hidden layer and it solves it almost immediately. That's the whole reason depth exists, and it's more convincing when you watch it fail first.
